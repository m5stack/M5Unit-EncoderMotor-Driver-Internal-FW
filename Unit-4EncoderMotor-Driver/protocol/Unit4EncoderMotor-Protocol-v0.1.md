### 4.3 Motor Speed

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x40 ~ 0x43` | `4 byte` | `R` | 读取 4 路电机速度 |

#### 参数说明

| 地址/偏移 | 取值/范围 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `0x40` | `-127 ~ 127` | 运行时 | `Motor1_Speed`，`INT8` |
| `0x41` | `-127 ~ 127` | 运行时 | `Motor2_Speed`，`INT8` |
| `0x42` | `-127 ~ 127` | 运行时 | `Motor3_Speed`，`INT8` |
| `0x43` | `-127 ~ 127` | 运行时 | `Motor4_Speed`，`INT8` |

#### 注意事项

##### 1、电机编码器速度统计周期为 `20 ms`。`Motor Speed` 表示最近 `20 ms` 内的编码器计数增量，不是 RPM、PWM 占空比或线速度。

##### 2、`Motor Speed` 寄存器底层类型为 `INT8`，可表示 `-127 ~ 127`。实际可达速度受电机、负载、电源、电机驱动能力和编码器安装影响。当前标准电机/驱动配置实测最大约为 `±23`。

### 4.7 Motor4 Mode

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0x80 ~ 0x8C` | `13 byte` | `R/W` | Motor4 模式、位置环参数、速度环参数和目标值 |

#### 参数说明

| 地址/偏移 | 取值/范围 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `0x80` | `0 ~ 2` | 0 | `Motor4_Mode`：`0` Normal；`1` Position Lock；`2` Speed Lock |
| `0x81` | `0 ~ 255` | 3  | `Motor4_Position_P` |
| `0x82` | `0 ~ 255` | 1  | `Motor4_Position_I` |
| `0x83` | `0 ~ 255` | 15 | `Motor4_Position_D` |
| `0x84 ~ 0x87` | `INT32` | \ | `Motor4_Position_Point`，Position模式的目标位置，小端序：`byte0 + byte1 * 256 + byte2 * 65536 + byte3 * 16777216` |
| `0x88` | `-127 ~ 127` | 127 | `Motor4_Position_MAX_Speed` |
| `0x89` | `0 ~ 255` | 10 | `Motor4_Speed_P` |
| `0x8A` | `0 ~ 255` | 1  | `Motor4_Speed_I` |
| `0x8B` | `0 ~ 255` | 15 | `Motor4_Speed_D` |
| `0x8C` | `-127 ~ 127` | 5 | `Motor4_Speed_Point`，Speed模式的目标 `20 ms` 编码器增量 |

#### Motor1 ~ Motor4 Speed Point 通用说明

##### 1、`Motor*_Speed_Point` 为 Speed Lock 模式下的目标 `Motor Speed`，单位与 `0x40 ~ 0x43` 完全一致，均为 `20 ms` 编码器计数增量。

##### 2、`Motor*_Speed_Point` 寄存器底层类型为 `INT8`，协议层可写入 `-127 ~ 127`，但这不代表标准电机实际可以达到全范围速度。当前标准电机/驱动配置建议有效闭环目标范围为 `0, ±3 ~ ±23`；低于约 `±3` 时可能因电机静摩擦或启动死区无法稳定转动。

##### 3、当设置值超过实际可达速度时，固件会继续调节并可能使 PWM 输出饱和，`Motor Speed` 反馈值不保证达到 `Speed Point` 设定值。判断 Speed Lock 功能是否正常时，应优先使用实际可达范围内的目标值进行测试。

### 4.9 VIN ADC / VIN Voltage

| 地址/地址范围 | 长度 | 权限 | 功能说明 |
| :--- | :--: | :--: | :--- |
| `0xB0 ~ 0xB3` | `4 byte` | `R` | 读取 VIN ADC 原始值和 VIN 电压 |

#### 参数说明

| 地址/偏移 | 取值/范围 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `0xB0` | `0 ~ 255` | 运行时 | `ADC Value 12bits-L` |
| `0xB1` | `0 ~ 15` | 运行时 | `ADC Value 12bits-H`，12 bit ADC 高位 |
| `0xB2` | `0 ~ 255` | 运行时 | `VIN(mV)-LSB` |
| `0xB3` | `0 ~ 255` | 运行时 | `VIN(mV)-MSB` |

#### 注意事项

##### 1、ADC 原始值计算公式：`ADC = ADC_L + ADC_H * 256`，范围 `0 ~ 4095`。
##### 2、协议给出的电压换算公式：`Voltage = (ADC / 4095) * 3.3 / 0.16`。
##### 3、`VIN(mV)` 表示 VIN 实际电压，计算公式为：`VIN_mV = LSB + MSB * 256`。

##### 1、该寄存器写入的数据会自动保存到 Flash，请勿频繁写入，避免 Flash 损坏。
##### 2、地址写入后，固件会现场重新初始化 I2C 并立即使用新地址，不会重启设备。
